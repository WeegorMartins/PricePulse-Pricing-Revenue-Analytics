# Business Problem

PricePulse é um sistema de apoio à decisão de Pricing & Revenue Analytics.

## Objective

Usar histórico de vendas, preços e contexto comercial para identificar SKU-lojas em que alterações controladas de preço apresentam evidência suficiente para serem priorizadas como hipóteses de teste.

## Stakeholders

- Pricing Manager
- Revenue Growth Manager
- Category Manager
- Commercial Manager
- Finance
- Analytics / Data Science
- BI / Analytics Manager
- Executives

## Decisions Supported

- Testar aumento
- Testar redução
- Manter preço
- Investigar
- Classificar como evidência insuficiente
- Priorizar experimento

## Success Criteria

O projeto só é considerado completo se responder:

1. Onde existe oportunidade financeira?
2. Por que acreditamos nisso?
3. Quão confiável é a estimativa?
4. Onde não sabemos o suficiente?
5. Qual deveria ser o próximo teste?
