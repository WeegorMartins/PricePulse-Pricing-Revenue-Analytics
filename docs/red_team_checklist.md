# Red-Team Checklist

Before publishing:

- Did I call correlation "elasticity" anywhere?
- Did I imply causality from observational data?
- Did I publish a recommendation without uncertainty?
- Did I hide insufficient evidence?
- Did I treat simulated cost as observed?
- Did I invent competitor price?
- Did PVM reconcile exactly?
- Did I use weighted ASP rather than simple mean price?
- Did I keep scenario prices inside historical support?
- Did I show confidence intervals?
- Did I separate elasticity magnitude from evidence quality?
- Did I explain stockout/promotion limitations?
- Did I add tools that do not materially improve the problem?
- Can a manager understand the opportunity without reading code?
